<objective>
Add download retry on failure, small response detection to catch error JSON masquerading as audio, and FALLBACK track support for geo-restricted content.

Purpose: These are the resilience gaps — without retry, a single network hiccup fails the track permanently. Without small response detection, error JSON gets written as a corrupt audio file. Without FALLBACK, geo-restricted tracks fail with no alternative.

Output: 1-retry download, Content-Length based error detection, and geo-restriction fallback via alternative SNG_ID.
</objective>

  **Download retry (1 retry on failure):**

  1. In `downloadAndDecrypt()`, wrap the `downloadEncrypted()` call with a single retry:
     ```go
     err := d.downloadEncrypted(task, encPath, program, model)
     if err != nil {
         os.Remove(encPath)
         // Retry once
         if d.debug {
             fmt.Fprintf(os.Stderr, "Download failed, retrying: %v\n", err)
         }
         err = d.downloadEncrypted(task, encPath, program, model)
         if err != nil {
             os.Remove(encPath)
             return fmt.Errorf("download failed after retry: %w", err)
         }
     }
     ```

  **Small response detection:**

  2. In `downloadEncrypted()`, after getting the HTTP response and before starting the download loop, check Content-Length:
     ```go
     if totalSize > 0 && totalSize < 20*1024 {
         // Response is too small to be audio — likely error JSON
         body, _ := io.ReadAll(resp.Body)
         return fmt.Errorf("response too small (%d bytes), likely error: %s", totalSize, string(body))
     }
     ```
     This catches cases where the CDN returns an error page instead of audio. Place this check right after reading `resp.ContentLength` (around line ~905 in current code).

  **FALLBACK geo-restriction handling:**

  3. In `resolveMediaURL()`, after parsing the `MediaResponse`, check for error code 2002 in `mediaResp.Data[0].Errors`:
     ```go
     if len(mediaResp.Data) > 0 && len(mediaResp.Data[0].Errors) > 0 {
         for _, e := range mediaResp.Data[0].Errors {
             if e.Code == 2002 {
                 return "", &GeoRestrictedError{Code: e.Code, Message: e.Message}
             }
         }
     }
     ```
     Define a simple `GeoRestrictedError` type in `deezer.go`:
     ```go
     type GeoRestrictedError struct {
         Code    int
         Message string
     }
     func (e *GeoRestrictedError) Error() string {
         return fmt.Sprintf("geo-restricted (code %d): %s", e.Code, e.Message)
     }
     ```

  4. In `getStreamURL()`, when `resolveMediaURL` returns a `*GeoRestrictedError`, check if `songData.FALLBACK.SNG_ID` is non-empty. If so, fetch the fallback song data and retry:
     ```go
     mediaURL, err := d.resolveMediaURL(songData.TRACK_TOKEN, actualQuality)
     if err != nil {
         var geoErr *GeoRestrictedError
         if errors.As(err, &geoErr) && songData.FALLBACK.SNG_ID != "" {
             // Try fallback track
             fallbackData, fbErr := d.getSongData(songData.FALLBACK.SNG_ID)
             if fbErr == nil {
                 return d.getStreamURL(songData.FALLBACK.SNG_ID, quality, fallbackData)
                 // Note: recursive call — will try media API again with fallback track
             }
         }
         // Fall through to legacy CDN...
     }
     ```
     Add `"errors"` to imports. Use `errors.As` for type checking.

  5. Important: The recursive `getStreamURL` call should only happen once. To prevent infinite recursion, add a `fallbackAttempted bool` parameter or check if the songData is ALREADY a fallback (i.e., if songData.SNG_ID == songData.FALLBACK.SNG_ID, don't recurse). The simplest approach: since `getStreamURL` re-fetches songData via `getSongData`, and the fallback track's own FALLBACK field is typically empty, natural termination occurs. But add a safety check: only attempt fallback if `songData.FALLBACK.SNG_ID != songData.SNG_ID`.
