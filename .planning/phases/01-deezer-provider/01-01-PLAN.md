Create `provider/deezer/types.go` with all Deezer API response structs. Follow the same pattern as `provider/tidal/types.go`.

**Public API types** (JSON from `api.deezer.com`):
- `TrackResponse` — fields: ID (int), Title, TitleShort, ISRC, Duration (int, seconds), TrackPosition (int), DiskNumber (int), ReleaseDate (string), Preview (string), MD5Image (string), Artist (ArtistRef), Album (AlbumRef), Contributors ([]Contributor), Type (string)
- `AlbumResponse` — fields: ID (int), Title, UPC, CoverSmall/CoverMedium/CoverBig/CoverXL (string), MD5Image, GenreID (int), Genres (GenreList), Label, NbTracks (int), Duration (int), ReleaseDate, RecordType (string: "album"/"single"/"ep"/"compile"), Available (bool), Artist (ArtistRef), Tracks (TrackList), Type
- `ArtistResponse` — fields: ID (int), Name, Link, PictureSmall/PictureMedium/PictureBig/PictureXL, NbAlbum (int), NbFan (int), Type
- `ArtistRef` — fields: ID (int), Name, PictureSmall/Medium/Big/XL (optional)
- `AlbumRef` — fields: ID (int), Title, CoverSmall/Medium/Big/XL, MD5Image
- `Contributor` — fields: ID (int), Name, Role (string)
- `GenreList` — fields: Data ([]Genre)
- `Genre` — fields: ID (int), Name
- `TrackList` — fields: Data ([]TrackResponse)
- `ArtistAlbumsResponse` — fields: Data ([]AlbumResponse), Total (int), Next (string, URL for pagination)

**Private API types** (JSON from gw-light.php):
- `GWResponse` — generic wrapper: Error ([]interface{}), Results (json.RawMessage)
- `GWSongData` — fields: SNG_ID (string), SNG_TITLE (string), ALB_ID (string), ALB_TITLE (string), ALB_PICTURE (string), ART_ID (string), ART_NAME (string), DURATION (string), MD5_ORIGIN (string), MEDIA_VERSION (string), TRACK_TOKEN (string), TRACK_TOKEN_EXPIRE (int64), ISRC (string), DISK_NUMBER (string), TRACK_NUMBER (string), GAIN (string), FILESIZE_MP3_128 (string), FILESIZE_MP3_320 (string), FILESIZE_FLAC (string), COPYRIGHT (string)
- `GWUserData` — fields: USER (struct with OPTIONS containing LicenseToken, WebLossless bool, WebHQ bool), checkForm (string), SESSION_ID (string)
- `MediaRequest` / `MediaResponse` types for `media.deezer.com/v1/get_url`

**Auth types:**
- `Auth` — fields: ARL (string), SessionID (string), LicenseToken (string), APIToken (string, the checkForm value), UserID (string), CanStreamLossless (bool), CanStreamHQ (bool)

Use `json` struct tags. For the private API types, use the exact Deezer field names as JSON tags (e.g., `json:"SNG_ID"`, `json:"MD5_ORIGIN"`). For public API, use snake_case tags matching Deezer's API (e.g., `json:"track_position"`, `json:"disk_number"`, `json:"release_date"`, `json:"record_type"`).

Then create `provider/deezer/auth.go`:
- `SaveAuth(path string, auth Auth) error` — write auth JSON to file (0600 permissions), same pattern as tidal
- `LoadAuth(path string) (Auth, error)` — read auth JSON from file
- `InitSession(arl string) (*Auth, error)` — perform the full session initialization:
  1. Create an HTTP client with cookie jar
  2. Set the `arl` cookie on `https://www.deezer.com`
  3. POST to `https://www.deezer.com/ajax/gw-light.php?method=deezer.getUserData&input=3&api_version=1.0&api_token=` (empty api_token for first call)
  4. Parse the GWUserData response from `results`
  5. Extract: checkForm → APIToken, USER.OPTIONS.license_token → LicenseToken, USER.USER_ID → UserID, USER.OPTIONS.web_lossless → CanStreamLossless, USER.OPTIONS.web_hq → CanStreamHQ
  6. If USER_ID is 0 or empty, return error "invalid ARL — not logged in"
  7. Return populated Auth struct
- `EnsureAuth(authPath string, current Auth) (Auth, error)` — if current has valid ARL, re-init session (sessions expire). If no ARL, prompt user to provide one (print instructions with lipgloss styled text like Tidal does) and read from stdin. Save to disk.

Create `provider/deezer/deezer.go` implementing `provider.Provider`. Follow the same structure as `provider/tidal/tidal.go`.

**Package and imports:** `package deezer`, import `provider`, `ui`, `encoding/json`, `fmt`, `io`, `net/http`, `net/url`, `regexp`, `strconv`, `strings`

**Constants:**
- `PublicAPIBase = "https://api.deezer.com"`
- `GWLightBase = "https://www.deezer.com/ajax/gw-light.php"`
- `MediaAPIBase = "https://media.deezer.com/v1/get_url"`

**URL patterns** (regexp, support optional language prefix):
- `trackPattern = regexp.MustCompile("deezer\\.com(?:/[a-z]{2})?/track/(\\d+)")`
- `albumPattern = regexp.MustCompile("deezer\\.com(?:/[a-z]{2})?/album/(\\d+)")`
- `artistPattern = regexp.MustCompile("deezer\\.com(?:/[a-z]{2})?/artist/(\\d+)")`

**Struct:**
```go
type Deezer struct {
    auth       Auth
    authPath   string
    config     provider.Config
    httpClient *http.Client
    debug      bool

    OnAlbumsSelected func(albumURLs []string)
    OnAlbumComplete  func(albumURL string)
}
```

**Constructors:** `New(auth Auth, config provider.Config) *Deezer`, `NewWithPath(auth Auth, authPath string, config provider.Config) *Deezer`, `NewFromFile(authPath string, config provider.Config) (*Deezer, error)`

**Provider interface methods:**
- `Name() string` — return `"deezer"`
- `MatchesURL(url string) bool` — check all three patterns
- `URLType(url string) string` — return "track", "album", "artist", or ""
- `IsAuthenticated() bool` — return `d.auth.ARL != "" && d.auth.APIToken != ""`
- `SetDebug(enabled bool)`
- `SetAuth(auth Auth, authPath string)`
- `GetTrack(id string) (provider.Track, error)` — call public API `/track/{id}`, convert to provider.Track
- `GetAlbum(id string) (provider.Album, error)` — call public API `/album/{id}`, convert to provider.Album (include tracks)
- `GetStreamURL(trackID string) (string, error)` — stub returning error "not yet implemented" (Plan 02)
- `DownloadTrack(url string) error` — stub returning error "not yet implemented" (Plan 02)
- `DownloadAlbum(url string) error` — stub returning error "not yet implemented" (Plan 02)
- `DownloadArtist(url string) error` — stub returning error "not yet implemented" (Plan 02)

**Internal methods:**
- `publicAPICall(path string) ([]byte, error)` — GET `PublicAPIBase + path`, read body, debug log
- `gwAPICall(method string, params interface{}) (json.RawMessage, error)` — POST to GWLightBase with query params `method`, `api_version=1.0`, `api_token={d.auth.APIToken}`, `input=3`, `output=3`. Body is JSON. Set cookies: `arl={d.auth.ARL}`, `sid={d.auth.SessionID}`. Parse GWResponse, return Results.
- `getSongData(trackID string) (GWSongData, error)` — call gwAPICall with method `song.getData`, params `{"sng_id": trackID}`
- `getArtistAlbums(artistID string) ([]AlbumResponse, error)` — paginate through public API `/artist/{id}/albums?limit=50&index={offset}` using the `next` field
- `metadataToTrack(resp TrackResponse) provider.Track` — convert public API track to provider.Track. Map: ID→strconv.Itoa(resp.ID), Title→resp.Title, Artist→resp.Artist.Name, Album→resp.Album.Title, Duration→resp.Duration, TrackNumber→resp.TrackPosition, DiscNumber→resp.DiskNumber, ISRC→resp.ISRC, CoverURL→CoverURL(resp.Album.MD5Image, 1000)
- `CoverURL(md5 string, size int) string` — return `fmt.Sprintf("https://cdn-images.dzcdn.net/images/cover/%s/%dx%d-000000-80-0-0.jpg", md5, size, size)` or empty if md5 is empty

**URL helpers:** `ExtractTrackID(url) string`, `ExtractAlbumID(url) string`, `ExtractArtistID(url) string` — same pattern as Tidal.

**Quality mapping helper:**
```go
func deezerQuality(configQuality string) string {
    switch configQuality {
    case "FLAC", "LOSSLESS", "HI_RES_LOSSLESS":
        return "FLAC"
    case "HIGH", "MP3_320":
        return "MP3_320"
    default:
        return "MP3_128"
    }
}
```

**Release type formatting:**
```go
func formatReleaseType(recordType string) string {
    switch strings.ToLower(recordType) {
    case "album":
        return "Album"
    case "single":
        return "Single"
    case "ep":
        return "EP"
    case "compile":
        return "Compilation"
    default:
        return recordType
    }
}
```
