  <name>Task 1: Create Blowfish crypto module</name>
  <files>provider/deezer/crypto.go</files>
  <action>
Create `provider/deezer/crypto.go` with all cryptographic operations for Deezer stream decryption.

**Add `golang.org/x/crypto` dependency** — run `go get golang.org/x/crypto` for the blowfish package. Use `golang.org/x/crypto/blowfish` for the cipher and `crypto/cipher` for CBC mode.

**Constants:**
```go
const (
    blowfishSecret = "g4el58wc0zvf9na1"   // 16 bytes
    chunkSize      = 2048
    aesECBKey      = "jo6aey6haid2Teih"    // for legacy URL construction
    cdnSeparator   = "\xa4"                // ¤ (U+00A4)
)

var blowfishIV = []byte{0, 1, 2, 3, 4, 5, 6, 7}
```

**Functions:**

1. `DeriveBlowfishKey(trackID string) []byte`:
   - Compute `idMD5 = md5.Sum([]byte(trackID))` and hex-encode to 32-char lowercase string
   - XOR each byte: `key[i] = idMD5[i] ^ idMD5[i+16] ^ blowfishSecret[i]` for i in 0..15
   - Return 16-byte key

2. `DecryptStream(reader io.Reader, writer io.Writer, trackID string) error`:
   - Derive blowfish key from trackID
   - Create blowfish cipher: `blowfish.NewCipher(key)`
   - Read the input in 2048-byte chunks
   - For each chunk at index `i`:
     - If `i % 3 == 0` AND chunk is exactly 2048 bytes: decrypt with Blowfish CBC (reset IV to `blowfishIV` for each chunk — CBC state resets per chunk). Use `cipher.NewCBCDecrypter` with a fresh copy of blowfishIV each time.
     - Otherwise: write chunk as-is (plaintext)
   - Write each processed chunk to writer
   - Return nil on success

3. `BuildLegacyCDNURL(md5Origin, sngID, mediaVersion, quality string) (string, error)`:
   - Build plaintext: `md5Origin + cdnSeparator + qualityCode + cdnSeparator + sngID + cdnSeparator + mediaVersion`
   - Where qualityCode is: "1" for MP3_128, "3" for MP3_320, "9" for FLAC
   - Compute filenameHash: `hex(md5(plaintext)) + cdnSeparator + plaintext + cdnSeparator`
   - Pad filenameHash with spaces to nearest multiple of 16
   - Encrypt with AES-128-ECB using `aesECBKey` → hex-encode the ciphertext
   - CDN URL: `https://e-cdns-proxy-{md5Origin[0]}.dzcdn.net/mobile/1/{hexCiphertext}`
   - Note: AES-ECB is not in Go stdlib. Implement manually: `aes.NewCipher(key)`, then encrypt each 16-byte block independently with `cipher.Encrypt(dst, src)`.

4. `qualityToCode(quality string) string`:
   - "FLAC" → "9", "MP3_320" → "3", "MP3_128" → "1", default → "1"

**Important implementation notes:**
- The Blowfish CBC IV MUST be reset to `[0,1,2,3,4,5,6,7]` for EACH encrypted chunk (not carried over)
- Only decrypt chunks that are exactly 2048 bytes — short chunks at end of file are plaintext
- The AES-ECB for legacy URL uses standard Go `crypto/aes`, just encrypt block-by-block (no CBC mode)
- `golang.org/x/crypto/blowfish` provides `blowfish.NewCipher()` which returns a `cipher.Block` usable with `cipher.NewCBCDecrypter`

<task type="auto">
  <name>Task 2: Implement download methods with TUI</name>
  <files>provider/deezer/deezer.go</files>
  <action>
Replace the stub download methods in `deezer.go` with full implementations. Follow the exact same patterns as `provider/tidal/tidal.go` for TUI integration.

**Add these internal methods:**

1. `getStreamURL(trackID, quality string) (StreamInfo, error)`:
   - First try modern API: POST to `https://media.deezer.com/v1/get_url` with JSON body:
     ```json
     {
       "license_token": "{d.auth.LicenseToken}",
       "media": [{"type": "FULL", "formats": [{"format": "{quality}", "cipher": "BF_CBC_STRIPE"}]}],
       "track_tokens": ["{trackToken from song.getData}"]
     }
     ```
   - Parse response: extract `data[0].media[0].sources[0].url` as the stream URL
   - If modern API fails (401, empty result, etc.), fall back to legacy CDN:
     - Get song data via `getSongData(trackID)` (may already have it)
     - Call `BuildLegacyCDNURL(songData.MD5_ORIGIN, songData.SNG_ID, songData.MEDIA_VERSION, quality)`
   - Return `StreamInfo{URL, MimeType, IsEncrypted, SongData, RequestedQuality, ActualQuality}`
   
   Define `StreamInfo` struct:
   ```go
   type StreamInfo struct {
       URL              string
       MimeType         string
       IsEncrypted      bool     // true if URL contains "/mobile/" (legacy CDN)
       SongData         GWSongData
       RequestedQuality string
       ActualQuality    string
   }
   ```
   
   - MimeType: "audio/flac" for FLAC, "audio/mpeg" for MP3_128/MP3_320
   - IsEncrypted: true if URL contains `/mobile/` (legacy CDN URLs are always encrypted; modern media URLs use `cipher: "BF_CBC_STRIPE"` so they're also encrypted)
   - Actually: ALL Deezer streams from both APIs are Blowfish encrypted. Set `IsEncrypted = true` always.
   - Quality fallback: if FLAC requested but FILESIZE_FLAC is "0", try MP3_320. If that's "0", try MP3_128.

2. `downloadAndDecrypt(streamURL string, trackID string, filePath string, isEncrypted bool, progressFn func(downloaded int64, speed float64)) error`:
   - GET the stream URL with `provider.NewHTTPClient()`
   - If encrypted: pipe through `DecryptStream` writing to the output file
   - Implementation: create the output file, create a pipe (io.Pipe), start a goroutine that reads from HTTP response and writes to pipe writer (tracking bytes for progress), then in the main flow call `DecryptStream(pipeReader, outFile, trackID)`
   - Actually simpler approach: download entire stream to a temp file first, then decrypt to final file. Or better: use a custom `io.Reader` wrapper that decrypts on-the-fly as it reads.
   
   **Best approach for progress tracking:** Download to a temp buffer/file, tracking progress, then decrypt to final output:
   - Create temp file in same directory as output
   - Stream HTTP response to temp file, sending progress updates via the provided callback
   - After download complete, open temp file for reading, open output file for writing
   - Call `DecryptStream(tempReader, outWriter, trackID)`
   - Remove temp file
   - This matches how the Tidal provider works (download then process)

3. **Implement `DownloadTrack(url string) error`** — follow tidal.go DownloadTrack exactly:
   - Extract track ID from URL
   - Check auth
   - Use `ui.RunLoading` to fetch metadata:
     - Get song data via `getSongData(trackID)`
     - Get public track metadata for album info
     - Get album metadata for release date, album artist, cover URL
     - Get stream info via `getStreamURL`
     - Build filename via `provider.FormatFilename`
     - Build `ui.TrackInfo`
   - Create `ui.DownloadTask` (StreamURLs can be empty, just use StreamURL)
   - Create `ui.NewDownloadManager` and `dm.Run(tasks)`
   
   **IMPORTANT:** The standard `dm.Run()` uses its own `downloadFile` which does a plain HTTP download without decryption. For Deezer, we need to override this behavior. Two approaches:
   
   **Approach A (recommended):** Don't use `dm.Run()` directly. Instead, replicate the download flow manually:
   - Create the DownloadModel and tea.Program manually
   - Start downloads in a goroutine (same as manager.go's downloadAll)
   - In the download loop: download encrypted stream to temp file with progress tracking, then decrypt to final file, then tag, then probe
   - Send the same TrackStartMsg, TrackProgressMsg, TrackCompleteMsg, TrackErrorMsg messages to the program
   
   **Approach B (simpler, preferred):** Pre-download and decrypt to the final file path BEFORE calling the download manager. But this loses progress tracking.
   
   **Approach C (best):** Modify the download task to have a custom download function. Actually, looking at `ui/manager.go`, the `downloadFile` method downloads from `task.StreamURL` directly. For Deezer, we need to:
   1. Download the encrypted stream to a temp file
   2. Decrypt to the final file
   
   So: download the encrypted stream first, writing to a temp path, then decrypt in-place. The simplest approach: set `task.StreamURL` to the Deezer CDN URL, and after `dm.Run()` completes, post-process by decrypting each file. But `dm.Run()` already writes to `task.FilePath`.
   
   **Final approach:** The download manager in `ui/manager.go` downloads bytes directly to `task.FilePath`. For Deezer, the bytes are encrypted. So:
   1. Let `dm.Run()` download the encrypted bytes to the file path (it handles progress tracking)
   2. After dm.Run() completes, for each successfully downloaded track, decrypt the file in-place:
      - Read encrypted file → decrypt → write to temp → rename temp over original
   3. Then tag with ffmpeg (already done by dm.Run via TagAudioFile in downloadAll)
   
   Wait — looking at manager.go more carefully, `downloadAll` does: download → tag → probe all inside the goroutine. Tagging an encrypted file would fail. So we can't just let the manager run as-is.
   
   **ACTUAL best approach:** Override at the DownloadManager level. The `downloadAll` method calls `dm.downloadFile(task)` then `TagAudioFile`. We need the file to be decrypted BEFORE tagging.
   
   Implement it like this in `deezer.go`:
   - DON'T use `dm.Run(tasks)` — instead, create the download model + program manually (same as manager.go's Run), but run our own `downloadAllDeezer` goroutine that:
     1. For each task: send TrackStartMsg
     2. Download encrypted bytes to `task.FilePath + ".enc"` temp file (using same HTTP download code as manager's downloadFile, with progress messages)
     3. Decrypt: `DecryptStream(encFile, finalFile, trackID)` 
     4. Remove .enc temp file
     5. Tag with `provider.TagAudioFile`
     6. Probe with `provider.ProbeAudioFile`
     7. Send TrackCompleteMsg
   - Run the tea.Program
   
   Actually even simpler: just write a helper `downloadDeezerTrack(task, program, config)` that does download+decrypt+tag+probe and sends messages. Then for DownloadTrack/DownloadAlbum, create the model/program, launch the goroutine, and run the program.

   - Run `ui.RunFilter` for release type selection
